# alexw6385.github.io

My personal site: <https://alexw6385.github.io>

Plain HTML, CSS and JavaScript, no build step. The order-system and Polyphony panels are scripted
replays of each design that run in the browser; the real systems are in their own repositories.

- `index.html`, `site.css`, `site.js`: the page
- `orders.js`: the order-system replay (checkout, payment timeout, crash, duplicate request, flash sale)
- `mind.js`: the Polyphony replay (listen, speak, cadence)
- `media/`: screenshots and short clips of the projects
- `Alex_Wang_Resume.pdf`: resume

Preview locally with `python3 -m http.server` and open <http://localhost:8000>.
